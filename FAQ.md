
# Transfer Enchants — FAQ

Frequently asked questions about Transfer Enchants by TheBlueBoy.

## 1. What is Transfer Enchants?

Transfer Enchants is a Minecraft mod that lets players transfer enchantments between compatible items using an Enchantment Crystal and an Enchanting Forge.

## 2. Which Minecraft version does it support?

The current project is configured for Minecraft Java Edition 1.21.1. Check the Modrinth release page for the exact versions supported by each published release.

## 3. Which mod loader is required?

Transfer Enchants is built for Fabric. Make sure your Minecraft version, Fabric Loader, and mod version are compatible.

## 4. What is an Enchantment Crystal?

The Enchantment Crystal is used to store and transfer enchantments. It is designed to hold one enchantment at a time.

## 5. Can I transfer any enchantment?

Curses such as Curse of Binding and Curse of Vanishing are excluded from transfers according to the mod's intended rules. Other restrictions may depend on the item and enchantment.

## 6. Can I choose which enchantment to transfer?

The intended system allows you to select one enchantment when the source item has multiple enchantments.

## 7. Does the crystal have durability?

Yes. The crystal is designed to have limited uses. Its durability decreases as it is used, and it eventually breaks.

## 8. Does the XP cost increase?

Yes. The intended system increases the XP cost as the crystal is used more frequently.

## 9. What is the Enchanting Forge?

The Enchanting Forge is the block used for the enchantment-transfer process.

## 10. What if an item disappears from the forge?

First, check your inventory and relaunch the world only after making a backup if the issue persists. If an item appears to be lost, report the issue with the steps you followed and relevant logs.

## 11. What should I do if the mod crashes?

1. Confirm that the Minecraft and mod versions match.
2. Check that Fabric Loader is installed correctly.
3. Test whether the crash occurs without unrelated mods, if practical.
4. Submit a bug report and attach the crash report or relevant log.

The mod's source code is kept private. The public issue tracker is available for bug reports and suggestions.

Download releases from the official Transfer Enchants Modrinth project page. Always check the version and loader requirements before installing.
