## 1. Overview

Transfer Enchants is a Minecraft mod designed to move enchantments between compatible items using an Enchantment Crystal and an Enchanting Forge.

## 2. Requirements

Before installing:

- Use a Minecraft version supported by the specific mod release.
- Install the required Fabric Loader version.
- Install any dependencies listed on the Modrinth project page.
- Back up important worlds before testing new or updated mods.

## 3. Main Items and Blocks

### Enchantment Crystal

The crystal is designed to store a single enchantment. It is reusable, but its durability limits how many times it can be used.

### Enchanting Forge

The forge is the main block used to perform enchantment transfers. Place it in a suitable location and interact with it to open its interface.

## 4. Basic Workflow

The intended workflow is:

1. Obtain an Enchantment Crystal and the Enchanting Forge.
2. Place the forge and open its interface.
3. Place the required source item and crystal into their appropriate slots.
4. Select the enchantment you want to transfer, when selection is available.
5. Review the result and displayed XP cost.
6. Complete the transfer and collect the resulting item.
7. Check your inventory after closing the interface.

Exact recipes, slot layouts, and interaction details should match the installed release.

## 5. Crystal Durability and XP

The crystal has limited durability, and using it consumes durability. The intended XP cost increases with repeated use.

Check the in-game interface and the release notes for the exact costs and remaining uses in your version.

## 6. Restrictions

- The crystal is intended to store only one enchantment at a time.
- Curse of Binding and Curse of Vanishing are excluded from transfers.
- Item and enchantment compatibility may restrict which transfers are possible.
- Always check the result before completing a transfer.

## 7. Troubleshooting

### The forge does not open

- Confirm that you are using a compatible mod release.
- Try interacting with the block again.
- Check the game log for errors.

### The interface is missing textures or slots

- Confirm that the installed version is correct.
- Restart Minecraft after updating the mod.
- Report the problem with a screenshot if it continues.

### An item cannot be inserted

The item may not be valid for that slot or transfer operation. If a valid item is rejected unexpectedly, report the issue.

### The transfer does not work

- Check the item and enchantment compatibility.
- Check the crystal's condition.
- Review the displayed XP cost and any in-game messages.

### An item is missing after closing the forge

Check your inventory first. If the item remains missing, avoid repeating the operation until you have documented the problem.
